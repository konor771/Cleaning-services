CLEANING SERVICES WEBSITE

Open index.html in a browser to preview locally.

Files:
- index.html: website structure
- styles.css: responsive design
- script.js: interactions and language selector
- config.js: company contact settings
- assets/: favicon and design reference

Languages: English (default), Russian, Armenian, Mexican Spanish.
Use the language selector in the top-right corner. The selected language is saved in the browser.

Before publishing:
1. Edit config.js and set the real phone number and WhatsApp number.
2. Confirm or replace example prices and testimonials in index.html/script.js.
3. Upload the CONTENTS of this folder to the root of a GitHub repository.
4. Deploy on Render as a Static Site with Publish Directory set to .

No build command or environment variables are required.
